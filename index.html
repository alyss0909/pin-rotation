Back of House · 3.3 The Rotation

Set Up Your Pin Planner

To get your pin concierge assembled, you’ll need 2 free accounts; one to host your images and one to schedule your pin rotation. Don’t get spooked by the tech-bro names, I’ll walk you through each step of the way!

Step 1: Make a GitHub Account

We’ll use GitHub to host your pin images so Pinterest can access them.

Open GitHub Signup

Already have an account? Just enter your username below.

Step 2: Make Your Pin Image Folder

Click below to make a folder called pin-images, then click Create repository.

Make My Pin Images Folder

PS: make sure to keep the visibility public so Pinterest can post your images.

Step 3: Upload Your 70 Pins

Open the upload screen, drag in all 70 pin images at once, then click Commit changes when they’re finished loading.

Open Upload Screen

Then check your folder and make sure all 70 images are there.

Open My Folder

Enter your GitHub username in step one first.

Step 4: Set Up Zernio

Zernio is what will schedule and post your pins. Make a free account, connect Pinterest, then copy your API key.

Open Zernio Open My API Keys

Step 5: Back to Batch Prep

That’s the one-time setup done. Go back to the Batch Prep tab in your Pin Planner and work the checklist top to bottom. It takes it from here.
